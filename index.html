BAGIAN 01 · KOMPETENSI DASAR

Tujuan Pembelajaran

Setelah menyelesaikan modul multimedia ini, mahasiswa Program Studi PTIK diharapkan menguasai tiga capaian pembelajaran berikut:

Tujuan 1

Menjelaskan Konsep Dasar Algoritma Bubble Sort

Poin 01/03

Memahami prinsip fundamental perbandingan pasangan bersebelahan

Mahasiswa mampu menguraikan definisi, mekanisme komparasi data bersebelahan (adjacent comparison), serta analogi ilmiah bagaimana elemen berbobot terbesar mengapung ke posisi akhir larik seperti gelembung udara dalam cairan.

Indikator Pencapaian:
  • ✔ Prinsip perbandingan elemen bersebelahan: A[j] dengan A[j+1]
  • ✔ Sifat algoritma: Comparison-based, In-Place (hemat memori), dan Stable
  • ✔ Analogi gelembung: setiap putaran mengunci 1 elemen terbesar ke posisi akhir
Tujuan 2

Menerapkan Langkah-langkah Pengurutan Data

Poin 02/03

Melacak iterasi dan mengeksekusi proses pertukaran (swap) secara runtut

Mahasiswa mampu melacak dan mengeksekusi operasi penukaran (swap) nilai data pada setiap putaran (pass), memetakan pergeseran indeks, serta memahami penyempitan rentang pemeriksaan pada iterasi berikutnya.

Indikator Pencapaian:
  • ✔ Kondisi penukaran ascending: swap jika A[j] > A[j+1]
  • ✔ Penyusutan batas perbandingan: j berjalan dari indeks 0 hingga n - i - 1
  • ✔ Penetapan elemen terurut di akhir array pada tiap akhir putaran
Tujuan 3

Menganalisis Kompleksitas Waktu & Efisiensi Algoritma

Poin 03/03

Mengevaluasi kinerja Best Case, Worst Case, dan kebutuhan memori

Mahasiswa mampu menghitung jumlah operasi komparasi matematika, memahami kompleksitas waktu kuadratik O(n²), serta mengidentifikasi optimasi pendeteksian array yang telah terurut (Best Case O(n)).

Indikator Pencapaian:
  • ✔ Kasus Terburuk (Worst Case): O(n²) saat susunan data terbalik penuh
  • ✔ Kasus Terbaik (Best Case): O(n) dengan optimasi flag/boolean pertukaran
  • ✔ Kompleksitas Ruang (Space Complexity): O(1) karena bersifat In-Place

PRINSIP BUBBLE SORT

Mengapa Disebut "Bubble" (Gelembung)?

Algoritma ini dinamakan Bubble Sort karena elemen dengan nilai terbesar secara perlahan "mengapung" ke posisi akhir larik pada setiap akhir putaran, persis seperti gelembung udara dalam kolom air yang bergerak naik ke permukaan.

Aturan Penukaran (Swap):

Untuk setiap pasangan bersebelahan A[j] dan A[j+1]:

  • Jika A[j] > A[j+1]: TUKAR posisinya
  • Jika A[j] <= A[j+1]: JANGAN TUKAR (tetap)
STRUKTUR PERULANGAN (NESTED LOOP)
// Pseudocode C++ / Java / Python
for (i = 0; i < n - 1; i++) {
for (j = 0; j < n - i - 1; j++) {
if (A[j] > A[j + 1]) {
swap(A[j], A[j + 1]);
}
}
}
Worst Case Time O(n²) Larik terbalik
Best Case Time O(n) Sudah terurut
