BAGIAN 01 · KOMPETENSI DASAR

Tujuan Pembelajaran

3 Sasaran Kompetensi Siswa
Tujuan 1

Konsep Dasar Bubble Sort

01/03

Prinsip perbandingan elemen bersebelahan

Siswa mampu menguraikan definisi komparasi data bersebelahan dan analogi bagaimana elemen terbesar mengapung ke akhir larik.

Indikator Pencapaian:
  • ✔ Komparasi: A[j] vs A[j+1]
  • ✔ In-Place & Stable sort
  • ✔ Mengunci 1 elemen terbesar/pass
Tujuan 2

Langkah-langkah Pengurutan

02/03

Mengeksekusi pertukaran (swap) runtut

Siswa mampu melacak penukaran nilai tiap pass, pergeseran indeks, dan penyusutan rentang loop berikutnya.

Indikator Pencapaian:
  • ✔ Syarat swap: A[j] > A[j+1]
  • ✔ Rentang loop: j sampai n-i-1
  • ✔ Posisi final elemen terurut
Tujuan 3

Analisis Kompleksitas Waktu

03/03

Mengevaluasi efisiensi komputasi

Siswa mampu memahami kompleksitas waktu kuadratik O(n²), optimasi Best Case O(n), dan memori O(1).

Indikator Pencapaian:
  • ✔ Worst Case: O(n²) terbalik
  • ✔ Best Case: O(n) flag swap
  • ✔ Ruang: O(1) in-place memory

PRINSIP BUBBLE SORT

Mengapa Disebut "Bubble" (Gelembung)?

Elemen bernilai terbesar secara bertahap "mengapung" ke posisi paling akhir pada tiap putaran seperti gelembung udara dalam kolom cairan.

Aturan Penukaran (Swap):
• A[j] > A[j+1]: TUKAR posisi
• A[j] <= A[j+1]: TETAP (tidak ditukar)
STRUKTUR NESTED LOOP
for (i = 0; i < n - 1; i++) {
for (j = 0; j < n - i - 1; j++) {
if (A[j] > A[j+1]) swap(A[j], A[j+1]);
}
}
Worst Case: O(n²)
Best Case: O(n)
